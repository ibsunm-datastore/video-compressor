Privacy

Your video is processed inside this browser tab.
  • The file is never uploaded; there is no server and no public URL.
  • Hardware engine (MP4, MOV, MKV, WebM): uses the browser's built-in video encoder (WebCodecs) and your graphics chip — usually many times faster. Needs a small library (~0.3 MB) from jsDelivr.
  • FFmpeg engine (all other formats, remux, sped-up audio): FFmpeg compiled to WebAssembly, downloaded once (~31 MB) from unpkg.com and only when needed. Multi-threaded when the page is served over HTTPS.
  • Everything is cleared from memory when you press Reset or close the tab.

Limits: browser memory caps practical inputs at about 1–2 GB. The FFmpeg engine is slower than native FFmpeg; for it, the "Encoder speed" option trades compression efficiency for time.
